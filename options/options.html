일반 설정

페이지에서 텍스트 복사 시 자동으로 복사 기록에 저장합니다.

20초 이상 머문 페이지를 자동으로 방문 기록에 저장합니다.

블로그 글쓰기 페이지 방문 시 팝업을 자동으로 엽니다.

참고 목록에 자동으로 번호를 매깁니다 (1, 2, 3, ...).

🔒 복사 이력 보안

API 키, 토큰, 비밀번호, 신용카드 번호 등이 감지되면 복사 이력에 저장하지 않습니다.

민감 정보가 필터링될 때마다 알림을 표시합니다 (선택사항).

저장된 모든 복사 이력을 삭제합니다 (복구 불가능).

⚠️ 보안 권장사항: 민감한 정보를 자주 다루는 경우, "복사 이벤트 추적"을 비활성화하는 것을 권장합니다.

방문 추적 설정

방문 기록을 보관할 기간 (1-90일)

방문 기록에서 제외할 도메인 패턴 (한 줄에 하나씩, 예: *.amazon.com, *.shopping.*)

💡 20초 이상 머문 페이지만 자동으로 방문 기록에 저장됩니다. localhost, chrome:// 등은 자동 제외됩니다.
